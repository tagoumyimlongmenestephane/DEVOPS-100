pourquoi utiliser dynamo db?
S3 permet de stocker le fichier d'état, mais il ne fournit pas de mécanisme de 
verrouillage adapté aux opérations concurrentes. DynamoDB apporte cette protection.
S3 : stockage du fichier terraform.tfstate.
DynamoDB(no SQL Database) : verrouillage de l'état(la mémoire de l'infracstructure qu'il a créé) pour éviter les modifications simultanées.
Avantage : sécurité, cohérence et travail collaboratif sans risque de corruption du fichier d'état.


Bonnes pratiques:
 - Never store the Terraform state file locally or on GitHub.
 - Use a remote backend (e.g., AWS S3 with DynamoDB for state locking).
 - Never modify the state file manually.

Bonnes pratiques avec Terraform
 - Use modules to organize your code.
 - Separate your code into main.tf, variables.tf, and outputs.tf files.
 - Version your Terraform files using Git.
 - Run terraform plan before executing terraform apply.
