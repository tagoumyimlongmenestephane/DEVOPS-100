2. Différence entre AWS CLI et AWS CloudFormation

AWS CLI(Outil en ligne de commande, Impérative(étape par étape), Actions rapides(Listes s3, EC2),
Commandes shell)

AWS CloudFormation(Service de gestion d'infrastructure, Déclarative, Déploiement d'architecture complète, YAML ou JSON)

une Stack est un regroupement logique de ressources AWS créées à partir d'un template CloudFormation.

- Une instance EC2
