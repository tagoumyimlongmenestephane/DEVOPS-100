ou manuelles nécessaires pour accomplir un objectif précis ou finaliser un projet.

AWS Lambda is an AWS serverless compute service used to run 
applications or functions without managing servers.

Trigger(déclencheur) est un évènement qui déclenche l'éxécution de la fonction 
Lambda.
Exemples: API Gateway, s3, DynamoDB Streams, CloudWatch Events, SNS / SQS

Exercice:

Dans cet exercice, nous allons créer une fonction Lambda qui identifie les instantanés EBS 
qui ne sont plus associés à une instance EC2 active et les supprime afin de réduire les coûts de stockage.

La fonction Lambda effectuera les actions suivantes :

Récupération de tous les instantanés EBS(Elastic Block Storage) appartenant au compte AWS en cours ('self').
Récupération de la liste des instances EC2 actives (états "running" et "stopped").
Vérification de chaque instantané :
Si l’instantané est associé à un volume et que ce volume n'est plus attaché à aucune instance EC2 active, alors il est considéré comme obsolète.
Suppression des instantanés obsolètes pour optimiser les coûts de stockage.
Ce processus garantit que l'espace utilisé par les instantanés inutilisés est libéré, évitant ainsi des coûts supplémentaires pour des ressources non exploitées. 



Un volume EBS est un disque virtuel attaché à une instance EC2.
Un snapshot EBS est une sauvegarde de ce disque, stockée dans Amazon S3 (
de manière transparente par AWS).

Internet Get Way(IGW)(passerelle Internet) est le point de sortie et d'entrée qui
relie un réseau privé à l'internet public.

Dans le Cloud (ex. AWS, GCP) : Une Internet Gateway est un composant virtuel que l'on attache à un réseau virtuel 
(VPC) pour permettre aux serveurs qui y sont hébergés d'accéder à Internet et d'être accessibles depuis l'extérieur.

Le NACL(Network Access Control List)(pare-feu au niveau du subnet)
il contrôle le trafic entrant et sortant, il est stateless(les règles doivent 
être définies dans les deux sens).

Un Security Group est un pare-feu virtuel qui contrôle le trafic réseau entrant 
et sortant au niveau d'une ressource(comme une instance EC2 ou un serveur virtuel
dans le cloud)


Le NAT(Network Address Translation) est un mécanisme qui permet à plusieurs appareils
d'un réseau privé d'utiliser une seule adresse IP publique pour naviguer sur Internet.

Le CIDR(Classless Inter-Domain Routing) est une méthode de notation et d'allocation des
adresses IP qui permet de définir un sous-réseau et d'indiquer combien d'adresses IP
uniques y sont disponibles. On le reconnaît à sa forme caractéristique : 
une adresse IP suivie d'une barre oblique et d'un nombre (par exemple : 192.168.1.0/24).

notation CIDR:
  Une adresse IPv4 est composée de 32 bits au total
  Dans la notation 192.168.1.0/24, le nombre après le slash (/24) est appelé le masque de sous-réseau. 
  Il indique le nombre de bits fixés (la partie réseau).
  Les 24 premiers bits identifient le réseau (ils ne bougent pas).
  Les 8 bits restants ($32 - 24 = 8$) servent à numéroter les appareils dans ce réseau.
  Pour calculer le nombre d'adresses disponibles : $2^8 = 256$ adresses (de 192.168.1.0 à 192.168.1.255).
